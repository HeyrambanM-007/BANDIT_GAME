# Bandit Level 15

## Goal
Send the Level 15 password over TLS to localhost port 30001.

## Commands
```bash
cat /etc/bandit_pass/bandit15
openssl s_client -connect localhost:30001
```

## Key concepts
- Level 15 focuses on learning how to use Linux commands and basic cybersecurity/networking concepts.
- Use `man <command>` or `<command> --help` when you need command details.
