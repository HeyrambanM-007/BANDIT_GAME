# Bandit Level 5

## Goal
Find the 1033-byte, non-executable file.

## Commands
```bash
find inhere -type f -size 1033c ! -executable
cat <path>
```

## Key concepts
- Level 5 focuses on learning how to use Linux commands and basic cybersecurity/networking concepts.
- Use `man <command>` or `<command> --help` when you need command details.
