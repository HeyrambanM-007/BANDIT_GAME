# Bandit Level 14

## Goal
Send the Level 14 password to localhost port 30000.

## Commands
```bash
cat /etc/bandit_pass/bandit14
nc localhost 30000
```

## Key concepts
- Level 14 focuses on learning how to use Linux commands and basic cybersecurity/networking concepts.
- Use `man <command>` or `<command> --help` when you need command details.
